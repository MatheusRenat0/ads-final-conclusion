# Aula 02 — Restrições e Junções

> **Disciplina:** Programação de Banco de Dados
> **Professor:** Arthur

---

# Objetivo da Aula

Compreender o conceito de restrições em bancos de dados e sua importância para garantir a integridade e confiabilidade das informações. Também foram introduzidos os conceitos de junção (`JOIN`) para combinar dados provenientes de diferentes tabelas relacionadas.

---

# Conteúdo Estudado

* Restrições em banco de dados
* Chaves
* Domínio
* Integridade referencial
* Constraints
* `PRIMARY KEY`
* `NOT NULL`
* `UNIQUE`
* `CHECK`
* `DEFAULT`
* Junções (`JOIN`)
* `INNER JOIN`
* `LEFT JOIN`
* `RIGHT JOIN`
* Relacionamento entre PK e FK

---

Durante a aula foram apresentados exemplos de:

# Principais Conceitos

### Restrições

São regras aplicadas aos dados para garantir sua integridade e confiabilidade.

### JOIN

Permite combinar dados de diferentes tabelas utilizando colunas relacionadas.

### PK e FK

As chaves são utilizadas para estabelecer relacionamentos entre as tabelas.
