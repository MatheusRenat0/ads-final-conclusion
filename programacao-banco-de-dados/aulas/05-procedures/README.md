# Material complementar — Procedures

> Conteúdo de estudo elaborado a partir do plano de ensino. Os materiais disponíveis não confirmam data nem realização de aula sobre este tema.

## Objetivo

Uma stored procedure é uma rotina nomeada armazenada no servidor, invocada explicitamente com CALL. Pode receber parâmetros IN, OUT e INOUT e conter várias instruções.
