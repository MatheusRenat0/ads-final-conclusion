# Aula 03 — Visões (Views)

## Objetivo

Uma visão é uma consulta armazenada que apresenta dados derivados de uma ou mais tabelas. Ela não armazena, em geral, uma cópia independente das linhas; ao consultar a view, o MySQL executa a definição associada.
