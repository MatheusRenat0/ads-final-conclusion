## Sobre o Repositório

Este repositório reúne os conteúdos, atividades, exercícios, anotações e projetos desenvolvidos durante o último semestre do curso de Análise e Desenvolvimento de Sistemas.

O objetivo é centralizar toda a documentação acadêmica produzida ao longo do semestre, registrando a evolução dos estudos e consolidando os conhecimentos adquiridos durante a formação.

---

## Objetivo

- Documentar aulas e conteúdos ministrados;
- Organizar exercícios e atividades práticas;
- Registrar anotações e aprendizados;
- Consolidar os conhecimentos adquiridos durante a graduação;
- Construir um histórico técnico para futuras consultas.

---

## Disciplinas

| Disciplina | Descrição |
|------------|------------|
| Programação de Banco de Dados | Modelagem de dados, SQL, consultas, procedures e manipulação de bancos de dados. |
| Desenvolvimento Mobile | Desenvolvimento de aplicações móveis, interfaces e conceitos de usabilidade. |
| Gerenciamento de Projetos Ágil | Fundamentos de agilidade, Scrum, Kanban, planejamento e acompanhamento do trabalho. |
