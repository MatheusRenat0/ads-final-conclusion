# Anotações Pessoais

## Objetivos após a aula

- Revisar os conceitos fundamentais do desenvolvimento mobile.
- Compreender as diferenças entre aplicações Nativas, Híbridas e Multiplataforma.
- Estudar a sintaxe básica da linguagem Kotlin.
- Instalar e configurar corretamente o Android Studio.
- Explorar a interface da IDE e conhecer seus principais recursos.

---

## Plano de Estudo

- Revisar os conceitos apresentados na aula.
- Pesquisar a sintaxe básica da linguagem Kotlin.
- Assistir uma introdução ao Android Studio.
- Desenvolver pequenos exercícios para praticar lógica de programação em Kotlin.
- Preparar o ambiente de desenvolvimento para as próximas aulas.

---

## Observações

A primeira aula teve como objetivo apresentar a disciplina e os conceitos fundamentais do desenvolvimento de aplicações móveis. Foram apresentados os diferentes tipos de aplicações, a arquitetura básica de um aplicativo Android, as principais ferramentas de desenvolvimento e a linguagem Kotlin, que será utilizada durante todo o semestre.

Como preparação para as próximas aulas, pretendo reforçar os conceitos introdutórios, praticar lógica de programação utilizando Kotlin e me familiarizar com o Android Studio para iniciar o desenvolvimento dos primeiros projetos.
