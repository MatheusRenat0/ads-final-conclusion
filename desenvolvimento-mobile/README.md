# Desenvolvimento Mobile

> Documentação da disciplina de **Desenvolvimento Mobile** do curso de **Análise e Desenvolvimento de Sistemas**.

## Sobre

Este diretório reúne todo o conteúdo estudado durante a disciplina, incluindo anotações, exercícios, exemplos práticos, projetos e materiais de apoio.

O objetivo é documentar minha evolução ao longo do semestre, consolidar os conhecimentos em desenvolvimento de aplicações móveis e criar um material de consulta para estudos futuros.

---

## Objetivos

- Compreender os fundamentos do desenvolvimento mobile.
- Desenvolver aplicações utilizando Kotlin.
- Aprender a utilizar o Android Studio.
- Construir interfaces gráficas para dispositivos móveis.
- Desenvolver aplicações integradas com APIs e banco de dados.
- Aplicar boas práticas de arquitetura e desenvolvimento.
- Publicar aplicações Android.

---

## Conteúdo Programático

- Fundamentos e Ambiente de Desenvolvimento
- Interfaces Gráficas (UI)
- Lógica de Aplicações
- Integração com APIs
- Persistência de Dados
- Recursos do Dispositivo
- Segurança
- Testes
- Publicação de Aplicativos
