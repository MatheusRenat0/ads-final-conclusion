# Desenvolvimento Web Responsivo

> Documentação da disciplina de **Desenvolvimento Web Responsivo** do curso de **Análise e Desenvolvimento de Sistemas**.

## Sobre

Este diretório reúne os estudos de criação de páginas e interfaces web funcionais, responsivas e acessíveis com HTML, CSS e JavaScript, sem depender de bibliotecas externas. Para praticar basta um editor, um navegador e uma pasta com `index.html`, `styles.css` e `script.js`.

Cada aula segue o mesmo formato das demais disciplinas: `README.md` (objetivo), `anotacoes.md` (explicações, exemplos, exercícios e respostas comentadas) e `resumo-aula.md` (síntese para revisão).

---

## Objetivos

- Entender como a Web funciona (cliente, servidor e HTTP).
- Estruturar páginas com HTML semântico e estilizá-las com CSS moderno.
- Construir layouts com Flexbox, Grid e media/container queries.
- Adicionar interatividade com JavaScript (DOM, eventos e formulários).
- Aplicar acessibilidade, usabilidade e boas práticas.

---

## Conteúdo Programático

- Fundamentos da Web e HTML semântico
- CSS, seletores, especificidade e box model
- Flexbox e CSS Grid
- Design responsivo e media queries
- Fundamentos de JavaScript, DOM e eventos
- Formulários e validação no frontend
- Acessibilidade, usabilidade e boas práticas
- Projeto prático — página responsiva
