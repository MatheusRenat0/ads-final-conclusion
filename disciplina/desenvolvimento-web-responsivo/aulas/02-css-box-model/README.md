# Aula 02: CSS, seletores, especificidade e box model

## Objetivo

Nesta aula: aplicar CSS por arquivo externo; usar seletores e entender especificidade, cascata e herança; usar variáveis CSS (custom properties); compreender o modelo de caixa; controlar tamanho, espaçamento e posicionamento; organizar CSS de forma sustentável (convenção BEM).
