# Resumo: CSS, seletores, especificidade e box model

CSS aplica regras por seletores. A cascata decide conflitos por importância, especificidade e ordem; prefiro classes e evito !important. Variáveis CSS e @layer ajudam a organizar o tema.

Toda caixa tem content, padding, border e margin; box-sizing: border-box facilita os cálculos. Uso display e position conscientemente e organizo os estilos com BEM e aninhamento nativo. As [anotações](./anotacoes.md) trazem os exemplos, os exercícios e as respostas comentadas.
