# Resumo: Formulários e validação no frontend

Formulários acessíveis têm label, type correto e autocomplete. Uso a validação nativa e a Constraint Validation API, com mensagens claras. A validação no cliente não substitui a do servidor. As [anotações](./anotacoes.md) trazem os exemplos, os exercícios e as respostas comentadas.
