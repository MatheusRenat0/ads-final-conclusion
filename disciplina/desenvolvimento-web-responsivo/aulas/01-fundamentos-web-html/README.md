# Aula 01: Fundamentos da Web e HTML semântico

## Objetivo

Nesta aula: explicar o modelo cliente-servidor e o ciclo requisição/resposta HTTP; diferenciar HTML, CSS e JavaScript; criar e abrir uma primeira página; usar elementos semânticos para dar significado ao conteúdo; construir listas, tabelas, links e imagens corretamente.
