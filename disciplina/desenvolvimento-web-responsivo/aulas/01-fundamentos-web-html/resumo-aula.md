# Resumo: Fundamentos da Web e HTML semântico

A Web funciona com clientes e servidores trocando requisições e respostas HTTP/HTTPS. HTML estrutura, CSS apresenta e JavaScript comporta. A meta viewport é essencial para páginas responsivas e as DevTools ajudam a inspecionar tudo.

HTML semântico descreve o significado do conteúdo (header, nav, main, article, section, footer). Mantenho títulos em ordem, uso alt nas imagens, tabelas só para dados e textos de link que façam sentido sozinhos. As [anotações](./anotacoes.md) trazem os exemplos, os exercícios e as respostas comentadas.
