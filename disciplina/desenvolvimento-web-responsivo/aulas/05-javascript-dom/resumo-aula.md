# Resumo: Fundamentos de JavaScript, DOM e eventos

Uso const e let, comparo com ===, escrevo arrow functions e trabalho com arrays (map, filter, reduce) e objetos (desestruturação e spread). Trato erros com try/catch e organizo o código em módulos.

O DOM é a árvore do documento. Seleciono com querySelector, altero classes e atributos, crio elementos e uso addEventListener e delegação de eventos. Prefiro textContent a innerHTML para evitar XSS. As [anotações](./anotacoes.md) trazem os exemplos, os exercícios e as respostas comentadas.
