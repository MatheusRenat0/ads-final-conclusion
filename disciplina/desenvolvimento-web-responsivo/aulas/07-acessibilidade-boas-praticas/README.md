# Aula 07: Acessibilidade, usabilidade e boas práticas

## Objetivo

Nesta aula: conhecer os princípios da WCAG (POUR); aplicar semântica, teclado, foco, contraste e ARIA; avaliar acessibilidade com ferramentas; estruturar um projeto web estático; aplicar boas práticas de desempenho, segurança e versionamento.
