# Plano de Ensino


## Objetivo

Desenvolver aplicações web em .NET: do pipeline HTTP e das APIs ao acesso a dados, segurança, interface, testes e publicação.

---

## Metodologia

- Leitura das anotações de cada aula
- Exemplos comentados
- Exercícios com respostas comentadas
- Desafios práticos


---

# Conteúdo Programático

- Introdução ao ASP.NET Core, ambiente e pipeline HTTP
- Minimal APIs, roteamento e validação
- MVC e Razor Pages: páginas renderizadas no servidor
- Acesso a dados com Entity Framework Core
- Web API REST com ASP.NET Core
- Autenticação e autorização com ASP.NET Core Identity
- Blazor: interfaces web interativas com C#
- Testes, observabilidade e publicação
