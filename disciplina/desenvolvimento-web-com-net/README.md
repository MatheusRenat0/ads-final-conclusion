# Desenvolvimento Web com .NET

> Documentação da disciplina de **Desenvolvimento Web com .NET** do curso de **Análise e Desenvolvimento de Sistemas**.

## Sobre

Este diretório reúne os estudos de desenvolvimento web com ASP.NET Core no .NET 10 (LTS) e C#: pipeline, Minimal APIs, MVC e Razor Pages, Entity Framework Core, Web API REST, Identity, Blazor, testes e publicação. Complementa [Programação Aplicada em .NET](../programacao-aplicada-em-net/README.md), [Programação de Banco de Dados](../programacao-banco-de-dados/README.md) e [Desenvolvimento Web Responsivo](../desenvolvimento-web-responsivo/README.md).

Cada aula segue o mesmo formato das demais disciplinas: `README.md` (objetivo), `anotacoes.md` (explicações, exemplos, exercícios e respostas comentadas) e `resumo-aula.md` (síntese para revisão).

---

## Objetivos

- Criar aplicações web com ASP.NET Core, middleware, configuração e injeção de dependência.
- Construir APIs REST (Minimal APIs e controllers) e páginas com MVC/Razor Pages.
- Persistir dados com Entity Framework Core.
- Proteger aplicações com Identity, autorização e boas práticas de segurança.
- Criar interfaces com Blazor, testar e publicar a aplicação.

---

## Conteúdo Programático

- Introdução ao ASP.NET Core, ambiente e pipeline HTTP
- Minimal APIs, roteamento e validação
- MVC e Razor Pages: páginas renderizadas no servidor
- Acesso a dados com Entity Framework Core
- Web API REST com ASP.NET Core
- Autenticação e autorização com ASP.NET Core Identity
- Blazor: interfaces web interativas com C#
- Testes, observabilidade e publicação
