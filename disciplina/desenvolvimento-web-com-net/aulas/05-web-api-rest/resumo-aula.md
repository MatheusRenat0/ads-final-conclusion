# Resumo: Web API REST com ASP.NET Core

APIs REST usam recursos, verbos e códigos HTTP corretos, DTOs para o contrato, [ApiController] para validação automática, ProblemDetails para erros, paginação com limite, CORS restrito, rate limiting e documento OpenAPI. IHttpClientFactory consome outras APIs. As [anotações](./anotacoes.md) trazem os exemplos, os exercícios e as respostas comentadas.
