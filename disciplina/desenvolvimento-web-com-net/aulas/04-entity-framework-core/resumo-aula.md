# Resumo: Acesso a dados com Entity Framework Core

O EF Core mapeia classes para tabelas e traduz LINQ em SQL parametrizado. Uso DbContext, migrações, AsNoTracking, projeções, paginação e Include para evitar o problema N+1, e retorno DTOs em vez de entidades. As [anotações](./anotacoes.md) trazem os exemplos, os exercícios e as respostas comentadas.
