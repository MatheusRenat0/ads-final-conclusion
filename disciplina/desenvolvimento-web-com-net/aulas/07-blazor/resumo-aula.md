# Resumo: Blazor: interfaces web interativas com C#

Blazor cria interfaces com C# e componentes Razor, com modos de renderização (SSR, Servidor, WebAssembly e Auto). Componentes têm parâmetros, eventos e formulários validados; consomem APIs via HttpClient. A autorização precisa existir também no servidor. As [anotações](./anotacoes.md) trazem os exemplos, os exercícios e as respostas comentadas.
