# Resumo: Introdução ao ASP.NET Core, ambiente e pipeline HTTP

ASP.NET Core roda no .NET 10 (LTS). O Program.cs configura serviços e o pipeline de middleware, cuja ordem importa. A configuração vem de appsettings, ambiente e segredos, e a injeção de dependência (singleton, scoped, transient) é nativa. As [anotações](./anotacoes.md) trazem os exemplos, os exercícios e as respostas comentadas.
