# Resumo: Minimal APIs, roteamento e validação

Minimal APIs declaram endpoints com MapGet/MapPost, recebem dados da rota, query e corpo e retornam TypedResults com os códigos HTTP corretos. Valido entradas (AddValidation no .NET 10), padronizo erros com ProblemDetails e documento com OpenAPI. As [anotações](./anotacoes.md) trazem os exemplos, os exercícios e as respostas comentadas.
