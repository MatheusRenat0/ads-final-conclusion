# Aula 05: DTOs e mapeamento de dados

## Objetivo

Separar os dados internos da aplicação dos dados que a API recebe e entrega, escolhendo um mapeamento adequado e evitando expor informações indevidas.

## Apresentação da aula

Records, Imutabilidade Funcional e Mapeamentos DTO, apresentado em sala de aula e disponibilizado no portal da faculdade (50 páginas).
