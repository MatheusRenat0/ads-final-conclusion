# Resumo: C# e .NET

C# é a linguagem de programação e .NET é a plataforma que oferece ferramentas, bibliotecas e runtime para criar e executar aplicações. Com eles podem ser construídas APIs, aplicações web e desktop, apps móveis, serviços e jogos.

O SDK ajuda a criar e compilar projetos. O CLR executa o programa e pode usar JIT para compilar código durante a execução; também existe AOT para cenários compatíveis. O runtime gerencia memória com coleta de lixo, mas arquivos, conexões e outros recursos devem ser fechados de forma controlada.

Veja as [anotações](./anotacoes.md) para os exemplos e a explicação do fluxo de execução.
