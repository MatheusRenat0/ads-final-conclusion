# Resumo da Aula 01 — Introdução ao Desenvolvimento Mobile

## 1. Visão Geral da Disciplina

A disciplina de Desenvolvimento Mobile tem como objetivo capacitar os alunos a desenvolver aplicações para dispositivos móveis utilizando ferramentas modernas e a linguagem Kotlin.

Ao longo do semestre serão estudados conceitos fundamentais do desenvolvimento Android, desde a configuração do ambiente até a criação de aplicações completas.

Os principais conteúdos previstos são:

- Fundamentos do desenvolvimento mobile
- Interfaces gráficas (UI)
- Desenvolvimento da lógica da aplicação
- Consumo de APIs
- Persistência de dados
- Recursos do dispositivo
- Segurança
- Testes
- Publicação de aplicativos

# 2. Conceitos Fundamentais

## O que é um programa?

Um programa é um conjunto de instruções responsáveis por executar uma determinada tarefa em um computador ou dispositivo móvel.

Uma forma simples de entender esse conceito é imaginar uma receita de bolo.

- Receita → Código
- Ingredientes → Dados
- Cozinheiro → Processador
- Bolo → Aplicação pronta

Assim como uma receita precisa ser seguida corretamente para produzir um bolo, um programa depende de uma sequência lógica de instruções para executar sua função.

---

## Algoritmos

Um algoritmo é uma sequência finita de passos utilizada para resolver um problema.

No desenvolvimento mobile, um bom algoritmo deve apresentar:

- Boa organização;
- Facilidade de manutenção;
- Baixo consumo de memória;
- Boa performance;
- Tempo de execução reduzido.

Também foi apresentado o conceito de **Big O Notation**, utilizado para medir a eficiência de algoritmos conforme aumenta a quantidade de dados processados.

# 3. Ecossistema Mobile

Foi realizada uma breve revisão sobre a evolução das redes móveis.

### 1G

Tecnologia analógica destinada apenas à realização de chamadas telefônicas.

### 2G

Introdução da comunicação digital e envio de mensagens SMS.

### 3G

Popularização da internet móvel.

### 4G

Maior velocidade de transmissão de dados e redução da latência.

### 5G

Nova geração de redes móveis, oferecendo velocidades muito superiores, baixa latência e suporte a tecnologias como Internet das Coisas (IoT) e Realidade Virtual.

# 5. Tipos de Aplicações Mobile

## Aplicações Nativas

Desenvolvidas especificamente para um único sistema operacional.

### Vantagens

- Alto desempenho;
- Maior segurança;
- Acesso completo aos recursos do dispositivo.

### Desvantagens

- Desenvolvimento separado para Android e iOS;
- Maior custo.

Linguagens utilizadas:

- Kotlin
- Java
- Swift

---

## Aplicações Híbridas

Aplicações desenvolvidas utilizando tecnologias web.

### Vantagens

- Código único;
- Desenvolvimento mais rápido.

### Desvantagens

- Menor desempenho;
- Limitações de acesso aos recursos do dispositivo.

---

## Aplicações Multiplataforma

Permitem utilizar uma única base de código para Android e iOS.

Principais frameworks:

- Flutter
- React Native
- Xamarin

Apresentam um equilíbrio entre produtividade e desempenho.

---

# 6. Arquitetura de Aplicações

Uma aplicação mobile normalmente é organizada em camadas.

As principais são:

- Usuário
- Interface (UI)
- Lógica de Negócio
- Camada de Dados
- Banco de Dados

Cada camada possui responsabilidades específicas e trabalha em conjunto para garantir o funcionamento correto da aplicação.

---

# 7. Ferramentas Utilizadas

## Kotlin

Linguagem oficial recomendada pelo Google para desenvolvimento Android.

Principais características:

- Código mais limpo;
- Sintaxe moderna;
- Maior segurança;
- Total integração com Java.

---

## Android Studio

IDE oficial para desenvolvimento Android.

Possui recursos para:

- Desenvolvimento de aplicações;
- Emulador Android;
- Criação de interfaces;
- Depuração;
- Gerenciamento do SDK.

Também foi apresentado o IntelliJ IDEA como ambiente de desenvolvimento para Kotlin.
