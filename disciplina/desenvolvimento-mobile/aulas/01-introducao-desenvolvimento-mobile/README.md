# Aula 01 — Introdução ao Desenvolvimento Mobile

> **Data:** 05/08/2026

---

# Objetivo da Aula

Apresentar a disciplina de Desenvolvimento Mobile, seus objetivos e a metodologia de ensino. Além disso, revisar conceitos fundamentais de programação, compreender o ecossistema mobile, conhecer os principais tipos de aplicações, sua arquitetura e as ferramentas que serão utilizadas durante o semestre, com foco na linguagem Kotlin e no Android Studio.

---

# Conteúdo Estudado

Nesta primeira aula foram abordados os seguintes temas:

- Apresentação da disciplina
- Conceitos fundamentais de programação
- Algoritmos
- Evolução das redes móveis
- Sistemas operacionais para dispositivos móveis
- Tipos de aplicações mobile
- Arquitetura de aplicações
- Linguagem Kotlin
- Android Studio
- Bibliografia da disciplina
