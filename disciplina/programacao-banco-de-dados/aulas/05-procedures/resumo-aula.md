# Resumo — Procedures

- Procedures são chamadas explicitamente com `CALL`.
- `IN`, `OUT` e `INOUT` definem a direção dos parâmetros.
- `SELECT ... INTO` pode atribuir resultado a variável local ou parâmetro.
- Handlers permitem definir comportamento para condições de erro.
- Transações exigem mecanismo transacional e responsabilidade bem definida.

Consulte [anotações](./anotacoes.md) para explicações, exemplos e exercícios, e [script SQL](./exemplos.sql) para os exemplos MySQL.
