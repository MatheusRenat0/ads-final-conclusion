# Minhas anotações — Revisão de SQL

Nesta aula revisei comandos que já tinha visto e organizei a diferença entre definir a estrutura do banco e manipular os registros. Quero praticar as consultas com uma base pequena para entender o resultado, não só decorar a sintaxe.

## O que quero fixar

- Retomar a base dos principais comandos da linguagem SQL.
- Revisar os conceitos fundamentais de Banco de Dados Relacional.
- Praticar comandos DDL, DML, DCL e DTL.
- Resolver exercícios práticos para reforçar o aprendizado.
- Criar exemplos próprios utilizando `SELECT`, `INSERT`, `UPDATE` e `DELETE`.

---

## Plano de Estudo

- Revisar a sintaxe dos comandos SQL.
- Praticar consultas utilizando filtros (`WHERE`), ordenação (`ORDER BY`) e agrupamentos (`GROUP BY`).
- Resolver exercícios de CRUD para ganhar mais familiaridade com a linguagem.
- Preparar a base necessária para os próximos conteúdos da disciplina, como **Views** e **Joins**.

---

## Observações

A primeira aula foi dedicada à revisão dos conceitos fundamentais de SQL. Como parte do meu plano de estudos para a disciplina, vou reforçar a base dos comandos SQL e realizar exercícios práticos para consolidar o conteúdo antes de avançar para os tópicos mais complexos.
