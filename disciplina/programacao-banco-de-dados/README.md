# Programação de Banco de Dados

> Documentação da disciplina de **Programação de Banco de Dados** do curso de **Análise e Desenvolvimento de Sistemas**.

## Sobre

Este diretório reúne todo o conteúdo estudado durante a disciplina, incluindo anotações, exercícios, exemplos práticos, projetos e materiais de apoio.

O objetivo é registrar minha evolução ao longo do semestre e consolidar o aprendizado em programação aplicada a bancos de dados.

---

## Objetivos

- Aprender SQL avançado.
- Desenvolver Procedures, Functions e Triggers.
- Compreender transações e concorrência.
- Aplicar técnicas de otimização de consultas.
- Criar um material de consulta e estudos.

---

## Conteúdo Programático

- Introdução / Revisão SQL
- Visão e Junção
- Restrições de Integridade
- Gatilhos (Triggers)
- Procedures
- Funções
- Transações / Concorrência
- Otimização de Consultas
